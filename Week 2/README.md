# Mini MapReduce Framework

## Description

This project implements a simple MapReduce framework in Python for Library Book Subject Analysis. The framework reads a dataset, maps book subjects into key-value pairs, partitions the data, sorts intermediate records, and reduces them to generate the final subject-wise book count.

## Features

- Mapper
- Partitioner
- Sorter
- Reducer
- Hash Partitioning
- Intermediate Files
- Final Output Generation
